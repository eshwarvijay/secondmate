- **Checker findings resolved, most severe first (all real, all independently reproduced by the supervisor before being routed to the maker or accepted as a checker claim):**
  1. **Fresh-HOME directory creation + swallowed heal failure** (checker round 1): both Bedrock fix functions failed outright on a brand-new pi install with no `~/.pi/agent/` directory at all (the exact case the check exists to heal), and `_heal_bedrock_overrides`'s own return status was discarded by `heal()`, so `--heal --yes` could report both fixes `[FAIL]` yet still exit 0. Fixed with `os.makedirs(..., exist_ok=True)` before each atomic write, and capturing/folding the heal's real exit code into `heal_failed`, matching the exact pattern the pre-existing secondmate-heal branch already used a few lines earlier in the same function.
  2. **Silent numeric-validation bypasses, found across three consecutive rounds** (checker rounds 2-3): a Python `bool` (subclass of `int`) passing an `isinstance(int, float)` check; then zero, negative, and fractional values; then `NaN`/`±Infinity` (accepted because IEEE-754 comparisons against `NaN` are always `False` in either direction). Closed for real only once consolidated into one robust check (`isfinite` + integral + positive + ceiling) applied identically to both validators, rather than three more one-off patches.
  3. **`_bedrock_fix_deepseek_r1` full-object-replace destroying custom fields** (checker round 4): directly contradicted this diff's own `docs/ARCHITECTURE.md` promise that "idempotent fixes preserve unrelated content." This corrected a judgment call the supervisor itself had explicitly told the maker was fine "by design" one round earlier — the supervisor's own mistake, corrected by the checker's citation of the diff's own documentation.
  4. **Shell-value-breaks-Python-string-literal class, found via a `redteam/injection` lens** (checker round 6): all four Bedrock `python3 -c` blocks interpolated shell variables directly into triple-quoted string literals; a `$HOME` path containing three consecutive apostrophes threw a `SyntaxError` and silently defeated detection/healing. Fixed generally (environment-variable passing for all four functions, not a narrow patch for the specific character), reusing a pattern that already existed elsewhere in the same file.
  5. **Recurring "fix shipped without permanent regression coverage" gap** (found independently at least three times across different specific fixes — rounds 2, 3, and 6): each time, the underlying fix was already correct and independently verified by the supervisor, but nothing in `--selfcheck` would catch a future regression of it.   6. **Symlink-invocation bug** (checker round 7): `_bedrock_get_model_id` shadowed the file's own pre-existing, correctly symlink-resolved global `$script_dir` with a naive local redeclaration, breaking Bedrock detection/healing entirely whenever `doctor.sh` was invoked through a symlink — even though the same file already fully supports symlink invocation for its own version-detection logic.
