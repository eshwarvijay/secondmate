- **Lesson:** two lessons this task. First, a maker's honest-sounding "this can't be done" claim about a technical constraint is worth independently verifying before accepting OR before blaming the maker for giving up — in this case the claim was false, but the supervisor's own first fix attempt was ALSO genuinely broken bash syntax, discovered only by testing the fragment standalone rather than assuming "exact verbatim code I wrote" is correct by authorship alone.
